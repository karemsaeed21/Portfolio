# Kareem Mohamed — Portfolio Website

Full-screen hero landing page & portfolio website built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features
- **Mouse-Scrubbed Background Video**: Interactive background video scrubbing controlled by horizontal mouse movement.
- **Hybrid Floating Glass Navbar**: Smooth morphing navbar from full-width top state to compact floating capsule on scroll.
- **Custom Typewriter Animation**: Interactive typewriter text with blinking cursor for A.R.I.A introduction.
- **Interactive Portfolio Sections**:
  - `About Me`: Machine Learning Engineering & AI Research bio, skills, profile photo, and CV download.
  - `Services`: Studio capabilities for Web Architecture, Custom Engineering, and Mobile Apps.
  - `Projects`: Filterable project grid with live & GitHub links.
  - `Shop`: Creative studio artifacts and hardware products.
  - `Contact`: Real-time contact form, email copy pill, and social connections (Twitter/X, GitHub, LinkedIn, Medium).

## Development Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates static production assets in the `dist/` directory.
